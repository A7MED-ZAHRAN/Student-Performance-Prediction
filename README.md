# 🎓 Student Performance Prediction

A complete Machine Learning project analyzing and predicting student performance based on historical features and study habits.

---

## 📌 Repository Contents
- **`Student_Performance.csv`**: The dataset containing features related to student habits and academic indicators.
- **`student_performance_model.joblib`**: The pre-trained serialized model ready for inference.
- **`Student_Performance_Prediction.ipynb`**: Complete end-to-end Jupyter Notebook containing EDA, preprocessing, model training, evaluation metrics, and visualizations.

---

## 📊 Pipeline Overview
1. **Exploratory Data Analysis (EDA):** Visual inspection of distributions, correlations, and feature impacts.
2. **Preprocessing:** Feature scaling and categorical encoding.
3. **Model Training:** Training regression/classification models.
4. **Evaluation:** Detailed performance evaluation using metrics and diagnostic plots.
